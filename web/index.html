Core Concept

把问卷、影像、智能分析、康复随访与医生沟通连成一条闭环。

先由脊柱健康 Agent 完成资料分流和病例建档，再按需进入影像分析、人工复核与长期趋势。每项结论都保留质量状态、来源和适用边界，而不是把多个模型堆成一个黑箱总分。

01

多模态输入

X 光侧重结构测量，DICOM 支持窗宽窗位，RGB 侧重低成本预筛和 X 光风格图辅助展示。

Measurement Map

指标不是孤立数字，而是脊柱排列关系的压缩表达。

右侧区块可展开查看指标意义和项目内参考分层。实际判断仍需结合年龄、症状、体位、片源质量和医生面诊。

提示：以下阈值用于系统展示和筛查分层，不等同于最终诊断标准。正式诊断需由专业医生结合完整影像和病史判断。

Clinical Indicators

主要测量指标与风险分层

工作台当前重点围绕腰椎侧位片中的曲度、骶骨倾斜、腰骶连接和节段位移进行辅助分析。

LL

腰椎前凸角 Lumbar Lordosis

反映腰椎整体前凸曲度，是评价腰椎排列和平衡的重要角度。

LL 偏低常见于腰椎变直、平背倾向或肌肉保护性紧张；LL 偏高可能提示腰椎过度前凸、骨盆前倾或腰骶负荷增加。

偏低参考：< 20°

提示曲度变直或平背倾向。

常见参考：20° 到 60°

处于较常见的腰椎前凸范围。

偏高参考：> 60°

可能提示过度前凸或腰骶应力增加。

SS

骶骨倾斜角 Sacral Slope / SA

描述骶骨上终板与水平线之间的夹角，和骨盆姿态、腰骶力线有关。

SS/SA 越大，常伴随骨盆前倾和腰椎前凸增加；过低则可能对应骨盆后倾和平背趋势。

偏低参考：< 30°

可能提示骨盆后倾或曲度不足。

常见参考：30° 到 50°

常作为较稳定的观察范围。

偏高参考：> 50°

可能和骨盆前倾、腰骶负荷增大相关。

LCA

腰骶连接角 Lumbosacral Curvature Angle

关注腰椎上端到骶骨上端之间的过渡夹角。

LCA 可帮助观察腰骶过渡段是否存在曲度异常、连接角改变或局部应力集中趋势。它适合和 LL、SS/SA、节段滑脱距离联合阅读。

轻度关注

角度轻微偏离，可作为复查参考。

中度关注

与其他指标同向异常时需复核。

重点关注

若伴随滑脱或疼痛，应进入专科评估。

LCI

腰椎曲度指数 Lumbar Curvature Index

本项目内用于描述局部椎体点到腰骶参考线的距离，单位为 mm。

当前算法以 L1 与 S1 背侧参考线为基准，计算局部关键点到该参考线的距离。它是项目中用于量化局部曲度和形态偏移的辅助参数。

轻度：< 5 mm

局部偏移较小，通常作为趋势记录。

中度：5 到 10 mm

提示局部曲度有可观察变化。

明显：> 10 mm

建议结合其他角度指标重点复核。

Slip

节段滑脱距离 Vertebral Translation

以相邻椎体参考点的位移距离筛查前滑脱或后滑脱倾向。

当前算法采用 mm 级位移阈值进行初筛。后续版本可继续加入 Meyerding 百分比分级、椎间隙高度和动态位移对比。

正常参考：≤ 3 mm

未见明显节段滑移趋势。

轻度异常：3 到 6 mm

提示轻度前滑或后滑。

明显异常：> 6 mm

需要医生结合影像进一步判断。

Algorithm Architecture

生成、分类、检测与测量模块共享同一个脊柱结构先验。

系统采用多任务迁移学习思路，把朝向分类、目标检测、关键点定位、生成式 X 光图和报告解释拆成多个可验证模块。每个模块解决一个明确问题，再通过工程工作流组合为端到端筛查能力。

End-to-end Flow

从输入图像到结构化结论

先标准化，再定位结构，随后测量与解释。这样比直接让一个模型输出结论更可控，也更容易定位错误来源。

Input Normalization读取 X 光、DICOM 或 RGB，完成灰度、尺寸、窗宽窗位和基础增强。
Orientation Classifier判断朝左或朝右，必要时自动镜像为统一的侧位方向。
ROI Detector定位脊柱区域，剔除背景干扰，为 RGB 裁剪和生成模块提供稳定输入。
Keypoint Detector定位椎体与骶骨关键点，交给几何引擎计算角度和距离。
Report Composer将指标、图像标注和解释文本组织为医生版与个人版报告。
Classification

左右朝向分类模型

输入缩放后的侧位图，输出朝左或朝右概率。它的价值不是炫技，而是保护后续测量坐标系，避免镜像方向导致角度和滑脱判断混乱。

Loss: L_cls = CE(y, p)
Output: left / right + confidence
Detection

脊柱 ROI 与椎体检测

检测模块负责从复杂背景中找到脊柱有效区域，并在 X 光图中识别椎体结构。它承担“先看哪里”的任务。

Loss: L_det = L_box + L_obj + L_cls
Output: bbox / ROI / confidence
Keypoints

关键点检测与几何测量

关键点模型输出椎体和骶骨参考点，几何层再计算 LL、SS/SA、LCA、LCI 和节段滑脱距离。测量逻辑独立，便于医生复核。

Loss: L_kp = L_coord + L_vis
Metrics: angle / distance / slip
Generation

RGB 到 X 光风格生成

生成模块采用 Pix2Pix 思路，将 RGB 体表图像映射到 X 光风格表达，用于低成本预筛和可视化解释。它不是替代真实影像，而是补充筛查入口。

Loss: L_gen = L_GAN + λL1 + L_edge
Backbone: U-Net G + PatchGAN D
Design Logic

损失函数对应的是系统稳定性的不同部分

分类损失保证方向一致，检测损失保证区域可靠，关键点损失保证测量点稳定，生成损失保证图像结构相似。把它们拆开训练和验证，可以让项目更像工程系统，而不是一张黑箱结果图。

CE 分类损失约束左右朝向判断，降低镜像错误。
Box / Obj 损失约束 ROI 和椎体边界，提升定位稳定性。
Keypoint 损失约束解剖关键点坐标，支撑角度测算。
GAN + L1 损失约束生成图既像 X 光，又保留体表结构线索。

迁移学习

用已有视觉模型能力迁移到脊柱场景，降低从零训练的数据压力。

多阶段回退

当直测失败时，通过扩边、增强、视野重建等策略提高闭环可用率。

几何后处理

把模型输出转化为可解释角度和距离，而不是只给出模糊标签。

医学可复核

保留关键点、测量线和原图对照，让医生能判断算法依据。

持续扩展

后续可加入骨刺、椎体形变、椎间距过窄和随访趋势分析。

Report System

同一组测量结果，拆成两种更适合真实沟通的报告。

医生需要可复核、可归档、可追溯的专业信息；患者需要能读懂、能沟通、能指导下一步行动的解释。报告系统的设计重点是把专业结论翻译成不同阅读对象需要的语言。

One Data Source

一组数据，两种表达

系统先生成统一的指标、标注图和辅助印象，再随着阅读对象分流为医生版和个人版。来源一致，表达不同。

Doctor Side

医生版报告

强调专业测量、结构化指标、影像标注和复核线索。

01
Detail / Feature / Content

为医生复核而设计

医生版报告保留专业参数与图像证据，重点服务门诊阅片、病例沟通和复查归档。

  • 包含 LL、SS/SA、LCA、LCI、节段滑脱距离等结构化指标。
  • 展示关键点、测量线、检测框和输入/输出图，便于追溯算法依据。
  • 语言更专业，重点描述影像发现、异常线索和需要医生复核的位置。
  • 适合医生快速筛查、康复随访对比、门诊报告归档和科研数据整理。
Patient Side + DeepSeek

个人版报告

强调通俗解释、风险提示、就医沟通和 DeepSeek 辅助生成的个性化建议。

02
DeepSeek-assisted Personal Report

为患者理解而设计

个人版报告在基础测量结果之外，可调用 DeepSeek 辅助生成更贴近患者阅读习惯的解释和建议，帮助患者知道下一步该问什么、做什么。

  • 减少术语堆叠，用通俗语言解释角度、曲度、滑脱等指标意义。
  • DeepSeek 辅助生成就医建议、就诊沟通要点、生活方式建议、风险提醒和复查提示。
  • 把专业影像指标转化为患者能理解的行动建议，提升医患沟通效率。
  • 明确说明“不替代医生诊断”，DeepSeek 内容只作为辅助解释和健康管理参考。
