# 脊柱知识索引第一版

本目录含 **55 条实际查阅支持的来源记录**，全部是自行撰写的短中文摘要与来源元数据，不含文章全文、患者病例、上传视频、密钥或模型工件。它是第一版精选知识索引，不是已穷尽的医学文献库，也没有临床签署。

来源覆盖 SRS、NHS、WHO、USPSTF、AAOS、NICE、ACR、ACR/RSNA、SOSORT、BrAIST 原研究、CDC、ScoNet 原论文和 NIAMS，并补充国家卫健委、国家疾控局、教育部公开政策、中华医学会、香港卫生署、SDSG 测量手册及施罗斯随机试验。一个来源可覆盖多个主题，主题数不能相加作为独立文献数；同一文件的镜像和翻译版没有重复计数。

## 资料范围

主题包括侧弯识别和测量、生长潜力、观察随访、支具、侧弯特异性训练、成人疼痛与退变、结构性后凸、骨质疏松骨折、影像选择、危险信号、步态平衡、跌倒、远程评估准备、心理支持和共同决策。扩充资料补齐中国学校筛查与档案转介、脊柱解剖、测量体位与平衡、炎性腰痛鉴别、术后早期照护、坐站和静态平衡测试及辅助技术。

医生与家庭是内部受众标签，儿童/青少年/成人是独立适用人群标签；标签不要求页面额外显示人群分区，也不能从医生或家长账号推断患者年龄。

## 来源与许可记录

`sources.json` 保存唯一 ID、原始来源 URL、出版机构、已确认的出处日期、2026-09-08 查阅日期、来源类型、证据描述、适用情况、限制、主题、受众、人群、用途和检索词。

- `access_mode=summary_only`、`full_text_indexed=false`：这一版只索引自行撰写的摘要。明确开放许可的论文已记录相应许可，但其全文也未纳入索引。
- `retrieval_method` 区分实际网页正文、官方 PDF 文本、搜索服务返回的原来源摘录和论文摘要；不将检索摘要冒充完整阅读。PMC 页面出现浏览验证时，保留已查看的原来源索引摘录并如实标记。
- `source_date=null` 表示查看的内容未提供可确认日期。部分来源只提供年份或年月，保留其原精度；不拿抓取日期替代出版日期。
- `source_license` 与 `license_note` 不重新授权来源。公开可读和开放许可是两回事；未来全文入库要单独核验许可、来源版本和可再分发范围。
- `evidence_level` 是来源性质的描述；没有假定所有指南推荐属于最高级证据，没有重新做完整 GRADE 评价。
- `clinically_signed_off=false`：所有摘要仍需根据拟部署范围进行专业复核。

## 保留有意义的差异

USPSTF 的无症状人群筛查 I 声明不能解释成反对对明显畸形者诊断。NHS 的一般运动信息与 SOSORT 的具体 PSSE 推荐需保留方法和证据差异。CDC TUG 的活动能力观察不能变成一个孤立的个体跌倒概率；NICE NG249 对风险预测工具另有明确限制。生长期支具的目标不能直接搬给成人。ScoNet 的算法论文只用于研究参考，与患者当前工具报告分开。

中国“五健”计划中的年度学校筛查是本地公共卫生实施要求，与 USPSTF 对筛查净获益的证据判断属于不同类型信息。学校筛查不能改写为每个学生每年拍片。健康姿势教育也不能改写为“不良坐姿导致全部特发性侧弯”或“普通体操能够治愈结构畸形”。

部分 2023 年 NHS 侧弯页面的计划复核日期已过；索引保留真实页面日期并提示与更新来源并读。NICE NG59 的条款跨 2016 和后续更新，使用时还应核对具体推荐；本版不是指南自动更新服务。

## 后续扩大

下一步按临床问题扩大独立来源和可许可全文。重点缺口包括具体医院转诊路径、成人脊柱畸形分层、不同术式专病康复、妊娠、神经肌肉及先天脊柱病、经验证的中文患者报告结局，以及已获准使用的量表。加入全文前保留 `summary_only` 标签。

`expansion_20260908.jsonl` 是20条已实际导入的增量批次，也可作为 JSONL 格式示例。重复导入会跳过完全相同记录；ID 或 URL 内容冲突会失败，不会静默替换。JSON Schema 见 `source.schema.json`，完整校验和命令见项目 `docs/rag_import_v1.md`。当前实际总数只统计 `sources.json`，不重复扫描增量文件。

检索实现与接口见项目 `docs/rag_implementation_v1.md`。
