# 成人脊柱健康 Agent：证据审计、问卷重构与信息架构草案

状态：**研发草案，尚未临床签署。** 本文不是诊疗指南，也不授权系统给患者生成诊断、药物建议或动作处方。

## 1. 诚实的当前状态

当前 `adult-spine-intake-v1` 只有成年确认、两项 0-10 主观评分及 8 个红旗。它适合做最低限度的安全阻断，**不全面，不能称为成人脊柱健康评估**。它没有完整的症状病程、功能、心理社会因素、既往治疗、脊柱侧弯随访和患者目标；若疼痛或活动受限未填，旧实现还会错误地产生 `routine`，这是必须修正的安全缺口。

当前个人检测页的 LL、SS/SA、LCA、LCI、节段位移属于既有影像分析链；不是 RepDetect、OpenCap、TotalSegmentator 或 MedRAG 的复现结果。视频页当前只做素材准备，不能显示或暗示已完成视频筛查。

## 2. 已解析的权威来源与可用边界

来源文件、SHA-256、许可证/使用说明和审核状态见 `knowledge_sources/source_registry.json`。

| 来源 | 已提炼的设计事实 | 可以支持 | 不能支持 |
| --- | --- | --- | --- |
| WHO 2023 慢性原发性腰痛指南快速参考 | 成人慢性原发性腰痛需要生物-心理-社会评估、及时转诊和按个人因素组合的非手术干预；教育、结构化运动和 CBT 等属于可能的组成部分；并非每个人都只需要一种处理。 | 问卷应覆盖症状、功能、心理社会与目标；康复必须是经审核目录中的组合计划。 | 自行诊断“慢性原发性腰痛”、开药、给所有人同一运动处方。 |

| SRS-22r 官方中文卷 | SRS 将其视作最新、最充分验证的患者结局量表，适用于成人；其页面说明超过 4 个漏答应视为无效。 | 有明确脊柱侧弯诊断/随访目标者的可选结局追踪，按领域展示。 | 红旗筛查、Cobb 角替代、把总分当疾病严重度。 |

SRS-22r 的成人测量学证据仍有局限；研究提示在成人脊柱畸形中更适合看领域分数而不是把多个维度压成一个总分。因此产品不显示“脊柱健康总分”，也不将问卷、影像和视频相加。

## 3. 问卷应该回答什么问题

问卷不是为了给用户贴疾病标签，而是为了给出**下一步、资料缺口和可比较的随访基线**。所有问题按目的分层，不混在一个长表单中。

### A. 两分钟安全分流（每次新问题或症状变化）

1. 年龄范围、知情同意、是否为本人填写。
2. 当前症状位置、开始时间、是否突然加重；背部痛、腿部放射痛/麻木/无力分别记录为“是否报告”，不由模型推断。
3. 红旗：新发大小便改变、鞍区感觉改变、进行性无力；严重外伤；发热/近期感染相关情况；肿瘤病史伴新发痛；不明原因体重下降；持续或进行性夜间痛。
4. 当前疼痛 NRS（0-10）与单项“关键活动受限”评分；两项均需填写或明确“不确定”。

输出只有 `urgent / priority_review / needs_clinical_review / incomplete / routine_follow_up`。红旗取最大严重度；`routine_follow_up` 的含义仅是“本次没有报告本问卷覆盖的高优先级信号”，绝不等于排除疾病。

### B. 初始评估模块（首次建档或症状变化后完成）

- 病程：首次发作/复发、持续时间、诱因、症状随日间或活动变化。
- 功能：步行、坐站、睡眠、工作/家务等由经审核的量表或短量表承载；若采用 PROMIS、ODI 或 STarT Back，必须先确认授权、官方中文版本和计分规则，禁止临时改写题目。
- 既往与风险背景：既往脊柱诊断/手术/外伤、骨质疏松或长期用药等仅由用户自报，并明确“未知”。
- 心理社会与生活情境：担忧/回避、睡眠、工作需求和可获得支持；这是 WHO 所要求的整体评估维度，不是心理诊断。
- 目标与偏好：用户希望改善的活动、可接受的采集方式、是否愿意医生协作。

输出是“需补全的资料”和“可讨论的管理路径”，不是病名或处方。

### C. 侧弯随访模块（仅在已知诊断、已有影像报告或医生邀请后出现）

- 既往医生记录的曲线位置、Cobb 角、检查日期、治疗状态与复查计划；禁止由自拍或视频填出 Cobb 角。
- 可选官方 SRS-22r 中文卷：保留原题、原选项、原计分及缺失判定；单独存为 `PROM` 记录。
- 影像、临床测量、SRS-22r 各自按日期、设备/协议和审核状态显示。只有同单位、同协议、同模型/人工流程才可比较。

输出为“本次资料是否可用于和既往对照”“哪些结局领域变化值得和医生讨论”，不是侧弯分级或治疗建议。

### D. 日常随访（30 秒）

仅复用已建立基线中的疼痛、关键活动受限、计划依从性、异常疼痛/红旗变化和用户自定目标。任何新红旗都跳回 A；异常疼痛或资料质量不足时停止自动康复任务并创建复核任务。

## 4. 产品信息架构：不再把所有能力挤进病例页

| 页面 | 用户只在这里完成的事 | 不应放入的事 |
| --- | --- | --- |
| **今天** | 下一步任务、红旗提示、30 秒随访、当日康复打卡。 | 全部历史、原始影像、复杂 Agent 配置。 |
| **评估** | 选择“问卷 / 已有 X 光或 DICOM / 体表照片 / 视频采集准备”，看到采集说明与质量状态。 | 直接把未验证 Worker 伪装成完成分析。 |
| **健康档案** | 按时间看问卷、PROM、影像、视频/三维资产、医生批注；每项有来源、质量、版本和可比性。 | 聊天输入与动作确认。 |
| **康复计划** | 经审核动作、禁忌/停止条件、日程、打卡和疼痛反馈。 | LLM 自由生成的运动处方。 |
| **Agent 助手** | 围绕当前病例提问；显示证据卡、拟执行操作和单次确认。 | 代替档案或承担紧急分诊。 |
| **专业工作台** | 受邀医生的影像审阅、批注、重跑、复核和导出。 | 患者日常打卡。 |

病例不是一个页面，而是贯穿以上页面的权限与时间线主键。页面顶部显示当前病例与切换入口，避免用户在不同页面丢失上下文。

## 5. 进入生产前的硬门禁

1. 临床审核人签署红旗措辞、分流时限、例外情况和可见文案。
2. 对每个正式量表确认原版、中文版本、授权、完整性规则和计分实现；建立逐题/逐分黄金样例。
3. 问卷缺失项必须产生 `incomplete`，不得默认为低风险；跨版本问卷不可直接画趋势。
4. SRS-22r、影像、视频与康复依从性分栏呈现，禁止合成为疾病概率或总分。
5. 仅将临床审核通过的原子化事实块入患者知识库；原始 PDF、研究笔记和研发知识库与病例事实库隔离。
