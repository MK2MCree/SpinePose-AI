# 脊见智诊 Android（本地原型）

本目录是独立安卓工程。首页复用网页品牌 Logo 和白紫色视觉，提供本机文字/照片档案、四视角拍前引导、系统相机拍照和系统图片选择器。系统相机取景画面由系统提供；引导为拍照前的说明，并未实现实时画面叠加或姿态检测。

记录详情中可将单张原始图片导出到用户选择的位置，再由用户在浏览器网页中手动选择。导出保留原始图片字节和可能存在的 EXIF 元数据；没有自动上传或自动同步。

这是早期原型，本应用不直接调用网络或模型，支持用户设置个人网站根地址，通过系统浏览器访问现有网页服务。支持 HTTPS，以及经用户明确确认的私有局域网 IPv4 HTTP；HTTP 明文传输不适合敏感数据。手机和电脑同网不保证可达，服务仍须配置为允许手机访问。网页账号、模型分析和服务器数据由浏览器和对应服务处理；手机本地记录、问卷与图片不会自动上传或同步。照片复制到应用私有目录，与记录保存在设备上；卸载或清除数据会删除这些内容。设置中可手动导出包含档案文字和照片的 ZIP，不包含问卷，暂不支持导入恢复。包含基于网页模板的本地问卷，包含固定安全提示，但不提供评分或综合分析。

## 构建条件

- Android Studio，Android SDK Platform 35，Android SDK Build Tools，以及兼容 Android Gradle Plugin 8.7.3 的 Gradle 8.9。
- 初次同步需要能访问 Google Maven 和 Maven Central。使用 Android Studio 打开 `mobile/android` 后按 IDE 提示同步、安装 SDK；或使用本机 Gradle 8.9 运行 `gradle :app:assembleDebug`。
- 项目尚无 Gradle Wrapper。本机已使用 Android SDK 35、Gradle 8.9 和 JDK 21 构建包含单图导出的发布版，并用 Android SDK apksigner 完成签名和校验。
- Android 35 模拟器已验证：首次启动及隐私说明、拍前引导、系统相机拍照并保存、档案内查看照片、单图导出、问卷前两步与固定提示、网页地址设置界面。相册导入、重启后记录留存、完整问卷保存、实际网页服务连接和真机测试尚未验证。
- 使用正式签名发布时必须安全保存密钥和口令；不要将密钥文件、口令或 `local.properties` 放入 Git。

## 手机验证要点

确认冷启动、本地记录保存及重新打开、全部四个视角、拍照成功与取消、相册图片导入与取消、图片过大/损坏时的提示、删除记录、旋转屏幕与返回处理、不同屏幕尺寸和系统版本。界面和行为均需以 Android 模拟器与真机的实际结果为准。
