# 用安卓应用打开电脑上的网页工作台

安卓应用和网页端当前各自保存数据。手机拍摄的图片可从记录详情中选择“导出此图片”，保存后再在浏览器网页中手动选择上传；不会自动同步。图片的原始 EXIF 等元数据可能随导出保留。

## 准备网页服务

当前仓库的 `launcher.py` 和 `run_local.ps1` 默认只监听 `127.0.0.1`，手机无法直接访问电脑的这个地址；手机里的 `localhost` 也指手机自身。GitHub Pages 地址只提供静态演示，不提供账号、模型或实际的后端数据。

让电脑上的 FastAPI 服务在手机可访问的地址提供服务，并按部署环境正确配置账号、数据目录和访问控制。建议优先使用 HTTPS。服务是否可访问还取决于电脑防火墙和网络配置；不要直接将本地测试服务暴露到公网。

在可信的专用局域网内调试时，可先通过 Windows 的 `ipconfig` 查看电脑所连接网络的 IPv4 地址，例如 `192.168.1.10`；手机应连接到同一网络。启动本项目已有的 `main:app` 时，须显式绑定该内网地址和端口，而不是默认的 `127.0.0.1`，例如：

```powershell
python -m uvicorn main:app --host 192.168.1.10 --port 8000 --workers 1
```

请将示例地址替换为电脑当前实际的内网 IPv4；使用已安装本项目依赖的 Python 环境。只在授权范围内调整防火墙，测试结束后停止服务。HTTP 不加密，局域网中其他人可能读取或篡改内容，测试请使用虚构数据；处理敏感数据时请使用正确配置的 HTTPS。

## 在手机上打开

1. 打开应用“设置 → 设置网页服务地址”。
2. 输入服务根地址，例如 `http://192.168.1.10:8000`，保存前阅读局域网 HTTP 提示。正式 HTTPS 服务也可输入对应根地址。
3. 选择“在浏览器中打开网页端”，按网页端实际账号和服务状态使用。网页由系统浏览器运行，手机应用不会获得网页密码或 Cookie。

能打开网页不代表模型已加载、网页分析已可用，具体取决于电脑服务、模型及账号配置。手机本地问卷和档案仍独立保存。
