## 第三步：拍照和图片记录（已实现，待设备检查）

本轮功能范围：

| 入口 | 行为 |
| --- | --- |
| 引导拍摄 | 选择正面/侧面/背面/斜侧面，查看拍前提示，打开系统相机，返回后加入记录 |
| 选择本机图片 | 打开系统图片选择器，选图后复制到应用自己的目录 |
| 记录中的图片 | 展示缩略图、来源、视角和本地保存路径，允许移除或替换 |
| 图片记录 | 可以只保存图片和备注，不强制填写活动分钟数 |
| 原有活动记录 | 继续支持新增、编辑、删除、日期排序和七天汇总 |

拍前引导是应用内的说明页，系统相机界面由系统提供。当前不宣称在系统取景器内叠加自定义轮廓或进行实时识别。

每条记录最多 4 张图片，单张最多 20 MiB。取消、相机不可用、图片损坏或保存失败时保留当前草稿，不添加假附件。图片复制完成并保存记录后，重启仍应能查看；清理操作只作用于应用保存的副本，不删除用户相册原图。

JSON 导出是**记录表备份**，包含文字和图片元数据，不包含图片文件。在其他设备导入后，缺失图片应显示重新选择提示。卸载或清除应用数据会移除应用内记录和图片，应在设置和隐私说明中准确说明。

这是开发构建产物。正式上架时按照发布流程生成并签名 `.app` 软件包。

用户当前使用电脑模拟器。模拟器管理入口为 **Tools > Device Manager > Local Emulator**，工具栏已选用的设备为 Pura 90；运行配置选择 `entry`，点击绿色运行按钮。

需要验证：

1. 旧文字记录和旧 JSON 仍能打开、编辑和导入。
2. 新增图片记录、保存、关闭后重开，图片和路径仍可查看。
3. 相机或本机选图取消时，原草稿内容和已选图片保留。
4. 图片超限、损坏或系统相机不可用时显示提示。
5. 编辑移除图片后放弃修改，原记录与旧图片仍在。
6. 删除记录、清空和替换只清理不再被引用的应用内图片。
7. JSON 导出不包含图片二进制；导入后图片缺失有明确提示。
8. 小屏、字体放大、键盘遮挡和返回操作正常。

模拟器可验证页面和部分文件流程；系统拍照、真实成像与本机图片选择仍需真机确认。
